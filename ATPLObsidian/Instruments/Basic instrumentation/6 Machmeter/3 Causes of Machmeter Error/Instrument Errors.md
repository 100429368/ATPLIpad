The usual pressure instrument errors:
* Instrument error
* Manoeuvre induced error
* Position error
* Static/pitot system error.

There is no compressibility error because the machmeter measures the ratio of D/S. Because this ratio is precisely what is being measured combining the movement of the pitot and static capsules,compressibility error is removed.

Barometric error is irrelevant because there is no reference pressure. The instrument simply measures the ratio of static and pitot pressures.


The mechanical machmeter has no temperature error(which results from calibrating altimeters to ISA) because there is no reference to ISA. Temperature has no effect other than change the LSS
